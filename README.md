# roblox
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0, rebuilt as a roguelike melee wave-defense game with Ghost of Tsushima-inspired sword combat.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "roblox.rbxlx"
```

Next, open `roblox.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Controls

| Action | Input |
| --- | --- |
| Sword attack (3-hit stance combo) | Left Click / `R2` |
| Parry (tap), guard (hold) | `F` / `L2` |
| Directional dodge dash | `Q`, `Shift`, or `L1` + movement direction |
| Extra air jump | Press Jump mid-air (needs the *Double Jump* perk) |

Three attacks inside the `1.2s` combo window finish with the heavy finisher *Heaven's Fall*.

## Combat Systems

- **Telegraphed enemies.** Every swing shows a `1.0s` windup with an amber warning ring (`PARRY OR DODGE`). Unparryable "flash cuts" wind up fast and flash crimson (`DODGE!`) - a parry does nothing against them.
- **Parry.** Opens a `0.2s` window. A hit inside it is fully negated, the attacker is stunned for `1.5s`, and you get a `1.5s` counter window for double damage. Holding `F` past the window settles into a guard stance (65% damage reduction).
- **Dodge.** `1.0s` cooldown with `0.25s` of invincibility frames at the start of the dash; dodging is the only answer to unparryable attacks.
- **Poise.** Slashes chip enemy poise; at zero the enemy staggers and its windup is interrupted. Heavy finishers break most poise outright, and *Sunder* breaks it instantly.
- **Waves.** Each wave adds enemies, tightens spawn intervals, scales health/damage/speed and mixes in brutes and shinobi.
- **Perks.** Clearing a wave pauses spawning and deals three random cards; the next wave starts once every living player has picked (or after 30s).

## Project Layout

```
src/
  shared/                        -> ReplicatedStorage.Shared
    CombatConfig.luau            timings, combo steps, enemy archetypes, poses, attributes
    PerkDatabase.luau            perk registry, rolling, stat folding
    Remotes.luau                 remote/signal registry + payload types
  server/                        -> ServerScriptService.Server
    CombatServer.server.luau     attack/parry/dodge authority, stats, perk offers
    EnemyAI.server.luau          enemy rigs, telegraphs, strike resolution, poise
    WaveManager.server.luau      escalation curve, perk pauses, party heal
    KatanaFactory.luau           shared sword rig builder + arm poser
  client/                        -> StarterPlayer.StarterPlayerScripts.Client
    CombatController.client.luau input, camera shake/FOV, sword posing, telegraph UI
    PerkUI.client.luau           perk cards, wave banner, HUD, health bar
```

> **Rojo file naming:** a plain `*.luau` file syncs as a *ModuleScript*, so files that must run carry the `*.server.luau` (Script) or `*.client.luau` (LocalScript) suffix. Modules such as `CombatConfig.luau` and `KatanaFactory.luau` intentionally stay plain.

The server is authoritative: clients only send intent (`Attack`, `Parry`, `Dodge`, `SelectPerk`) and every request is validated against server clocks before it touches the world. Client-visible state travels through the attributes documented at the top of `CombatConfig.luau`.
